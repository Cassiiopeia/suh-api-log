# suh-api-log 3.0.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 라이브러리가 자체 로깅을 고집하던 구조를 걷어내고 상위 프로젝트의 log4j2/logback 설정에 완전 위임하며, 레거시 데드코드를 제거하고 주요 동작 전부를 옵션·교체 가능한 확장점으로 연다.

**Architecture:** 단일 아티팩트(`kr.suhsaechan:suh-api-log`)를 유지하고 내부를 `logging` / `spi` / `core` / `fetch` / `storage` / `render` / `integration` / `autoconfigure` 레이어로 나눈다. 로깅은 SLF4J → Log4j2 → JUL 순으로 런타임 탐지하는 파사드로 위임하며, 로깅 구현체는 전부 `compileOnly`라 consumer에게 어떤 의존성도 강제하지 않는다. 주요 컴포넌트 4종은 SPI 인터페이스로 노출하고 `@ConditionalOnMissingBean`으로 등록해 상위 프로젝트가 빈 하나만 등록하면 교체된다.

**Tech Stack:** Java 17, Gradle 8.14, Spring Boot 3.5.0 (autoconfigure만 `compileOnly`), Jackson, jsoup 1.18.1, springdoc 2.8.4 (`compileOnly`), JUnit 5 + `ApplicationContextRunner`

**관련 문서:** 스펙 `docs/superpowers/specs/2026-07-27-suh-api-log-3.0-design.md`, 이슈 [#17](https://github.com/Cassiiopeia/suh-api-log/issues/17)

## Global Constraints

- **Java 17**, Gradle 8.14. 빌드 검증은 `./gradlew build`, 단위 테스트는 `./gradlew test`.
- **라이브러리는 어떤 로깅 구현체도 consumer에게 강제하지 않는다.** `slf4j-api`·`log4j-api`·`springdoc`은 전부 `compileOnly`. `implementation`/`api`로 올리지 않는다.
- **`src/main/resources`에 `application.yml`·`application-test.yml`을 두지 않는다.** 라이브러리가 상위 프로젝트 설정을 오염시키는 경로다.
- **라이브러리는 상위 앱을 죽이지 않는다.** 설정 오류의 기본 반응은 `WARN` 후 자기 비활성화이며, 예외 전파는 `suhapilog.github.fail-fast=true`일 때만 한다.
- **상위가 막은 로그를 라이브러리가 뚫지 않는다.** `suhapilog.logging.level`은 추가 필터(범위를 좁히는 용도)이지 백엔드 레벨을 조작하는 옵션이 아니다.
- **설정 prefix는 `suhapilog`** 로 고정한다.
- 코드 주석은 한국어로, WHY 중심으로 간결하게 작성한다.
- 커밋 메시지에 `Co-Authored-By`, `Generated with Claude`, `🤖`, `@mention`을 절대 넣지 않는다. 형식은 `레거시 전면 개선 : 상위 프로젝트 로깅 설정 위임 및 확장 가능한 옵션 체계 도입 : {타입} : {설명} https://github.com/Cassiiopeia/suh-api-log/issues/17`.
- 작업 브랜치는 `20260727_#17_기능개선_전체_레거시_전면_개선_상위_프로젝트_로깅_설정_위임_및_확장_가능한_옵션_체계_도입`. `git push`는 사용자가 명시적으로 요청할 때만 한다.

```java
package kr.suhsaechan.suhapilog.logging;

/**
 * 백엔드 중립 로그 레벨. 서열 비교로 {@code suhapilog.logging.level} 필터를 구현한다.
 */
public enum LogLevel {
  TRACE, DEBUG, INFO, WARN, ERROR;

  /** this가 other 이상인지 (ERROR.isAtLeast(WARN) == true) */
  public boolean isAtLeast(LogLevel other) {
    return this.ordinal() >= other.ordinal();
  }

  /** 설정값 파싱. 알 수 없는 값이면 null을 반환해 호출부가 "미설정"으로 처리하게 한다. */
  public static LogLevel parseOrNull(String value) {
    if (value == null || value.isBlank()) {
      return null;
    }
    try {
      return LogLevel.valueOf(value.trim().toUpperCase());
    } catch (IllegalArgumentException e) {
      return null;
    }
  }
}
```

- [ ] **Step 5: `JulMessageFormatter` 작성**

SLF4J/Log4j2는 `{}`를 네이티브 지원하므로 이 포맷터는 JUL 폴백 경로에서만 쓴다.

```java
package kr.suhsaechan.suhapilog.logging;

import java.util.Arrays;

/**
 * SLF4J 스타일 {} 플레이스홀더 포맷터.
 *
 * <p>SLF4J·Log4j2 어댑터는 포맷팅을 백엔드에 위임하므로 이 클래스를 쓰지 않는다.
 * JUL은 {} 문법을 모르기 때문에 폴백 경로에서만 필요하다.
 */
final class JulMessageFormatter {

  private JulMessageFormatter() {
  }

  static String format(String message, Object... args) {
    final String msg = String.valueOf(message); // null -> "null"
    if (args == null || args.length == 0) {
      return msg;
    }

    StringBuilder result = new StringBuilder(msg.length() + 16 * args.length);
    int argIndex = 0;
    int i = 0;

    while (i < msg.length()) {
      // 이스케이프된 플레이스홀더 \{} 는 리터럴 {} 로 남긴다
      if (i <= msg.length() - 3 && msg.charAt(i) == '\\' && msg.charAt(i + 1) == '{'
          && msg.charAt(i + 2) == '}') {
        result.append("{}");
        i += 3;
        continue;
      }
      if (i <= msg.length() - 2 && msg.charAt(i) == '{' && msg.charAt(i + 1) == '}') {
        if (argIndex < args.length) {
          result.append(formatArg(args[argIndex++]));
        } else {
          result.append("{}"); // 인자가 부족하면 그대로 유지
        }
        i += 2;
      } else {
        result.append(msg.charAt(i));
        i++;
      }
    }

    return result.toString();

      if (arg instanceof float[] a) return Arrays.toString(a);
      if (arg instanceof boolean[] a) return Arrays.toString(a);
      if (arg instanceof char[] a) return Arrays.toString(a);
      if (arg instanceof byte[] a) return Arrays.toString(a);
      if (arg instanceof short[] a) return Arrays.toString(a);
```

- [ ] **Step 6: `LoggerBackendResolver` 작성**

어댑터 클래스는 탐지 성공 **이후에만** 로드된다. `create()`가 호출되기 전까지 `Slf4jLoggerAdapter`는 링크되지 않으므로, slf4j-api가 없는 환경에서도 `NoClassDefFoundError`가 나지 않는다.

```java
package kr.suhsaechan.suhapilog.logging;

/**
 * 클래스패스를 보고 로깅 백엔드를 결정한다.
 *
 * <p>ClassLoader를 인자로 받는 이유는 테스트에서 FilteredClassLoader로 클래스패스
 * 변형을 재현하기 위해서다.
 */
final class LoggerBackendResolver {

  private LoggerBackendResolver() {
  }

  /**
   * 탐지 순서: SLF4J(바인딩 있음) → Log4j2 → JUL.
   *
   * <p>상위가 spring-boot-starter-log4j2를 쓰면 slf4j-api와 log4j-api가 모두 존재하고
   * SLF4J가 log4j2로 라우팅되므로, SLF4J를 1순위로 두어도 log4j2 설정이 적용된다.
   */
  static LoggerBackend detect(ClassLoader classLoader) {
    if (hasBoundSlf4j(classLoader)) {
      return LoggerBackend.SLF4J;
    }
    if (isPresent("org.apache.logging.log4j.LogManager", classLoader)) {
      return LoggerBackend.LOG4J2;
    }
    return LoggerBackend.JUL;
  }

  /**
   * SLF4J 2.x는 provider를 못 찾으면 NOPLoggerFactory를 돌려주고 로그를 전부 버린다.
   * 이 상태로 SLF4J를 고르면 로그가 통째로 사라지므로 다음 후보로 넘긴다.
   */
  private static boolean hasBoundSlf4j(ClassLoader classLoader) {
    try {
      Class<?> loggerFactory = Class.forName("org.slf4j.LoggerFactory", true, classLoader);
      Object factory = loggerFactory.getMethod("getILoggerFactory").invoke(null);
      return factory != null && !factory.getClass().getName().contains("NOP");
    } catch (Throwable e) {
      // ClassNotFound / LinkageError / provider 초기화 실패 전부 "SLF4J 사용 불가"로 본다
      return false;
    }
  }

  private static boolean isPresent(String className, ClassLoader classLoader) {
    try {
      Class.forName(className, false, classLoader);
      return true;
    } catch (Throwable e) {
      return false;
    }
  }

  static SuhLogger create(LoggerBackend backend, String name, ClassLoader classLoader) {
    LoggerBackend resolved = (backend == null || backend == LoggerBackend.AUTO)
        ? detect(classLoader)
        : backend;

    try {
      return switch (resolved) {
        case NONE -> NoOpLogger.INSTANCE;
        case SLF4J -> new Slf4jLoggerAdapter(name);
        case LOG4J2 -> new Log4j2LoggerAdapter(name);
        default -> new JulLoggerAdapter(name);
      };
    } catch (Throwable e) {
      // 강제 지정한 백엔드가 실제로는 클래스패스에 없는 경우 — 로그를 잃지 않도록 JUL로 내린다
      return new JulLoggerAdapter(name);
    }
  }
}
```

```java
package kr.suhsaechan.suhapilog.logging;

import java.util.concurrent.atomic.AtomicInteger;

/**
 * 로깅 오버라이드 설정 홀더.
 *
 * <p>정적 로거는 Spring 컨텍스트보다 먼저 만들어지므로, 설정을 로거 인스턴스에
 * 박아두지 않고 이 홀더를 매 호출 시 읽는다. 설정이 바뀌면 generation이 올라가고
 * 각 로거가 델리게이트를 다시 해석한다.
 */
public final class SuhLogSettings {

  private static volatile boolean enabled = true;
  private static volatile LogLevel minLevel = null;
  private static volatile LoggerBackend backend = LoggerBackend.AUTO;
  private static final AtomicInteger GENERATION = new AtomicInteger();

  private SuhLogSettings() {
  }

  public static boolean isEnabled() {
    return enabled;
  }

  /** null이면 "제한 없음" — 백엔드 판단에 전적으로 맡긴다. */
  public static LogLevel getMinLevel() {
    return minLevel;
  }

  public static LoggerBackend getBackend() {
    return backend;
  }

  public static int generation() {
    return GENERATION.get();
  }

  public static void apply(boolean newEnabled, LogLevel newMinLevel, LoggerBackend newBackend) {
    enabled = newEnabled;
    minLevel = newMinLevel;
    backend = (newBackend == null) ? LoggerBackend.AUTO : newBackend;
    GENERATION.incrementAndGet();
  }

  /** 테스트 및 컨텍스트 재기동용 — 기본값(전부 상위 위임)으로 되돌린다. */
  public static void reset() {
    apply(true, null, LoggerBackend.AUTO);
  }
}
```

```java
package kr.suhsaechan.suhapilog.logging;

/**
 * enabled / minLevel 필터를 적용하고, 설정 변경 시 델리게이트를 다시 해석하는 데코레이터.
 *
 * <p>minLevel은 "추가 필터"다. 상위가 이미 막은 레벨을 이 옵션으로 열 수는 없다 —
 * 그건 상위 로깅 설정의 권한이며 라이브러리가 침범하지 않는다.
 */
final class GuardedLogger implements SuhLogger {

  private final String name;
  private final ClassLoader classLoader;

  private volatile SuhLogger delegate;
  private volatile int delegateGeneration = -1;

  GuardedLogger(String name, ClassLoader classLoader) {
    this.name = name;
    this.classLoader = classLoader;
  }

  private SuhLogger delegate() {
    int current = SuhLogSettings.generation();
    SuhLogger local = delegate;
    if (local == null || delegateGeneration != current) {
      local = LoggerBackendResolver.create(SuhLogSettings.getBackend(), name, classLoader);
      delegate = local;
      delegateGeneration = current;
    }
    return local;
  }

  /** 라이브러리 단 필터. 백엔드 레벨 판단은 델리게이트가 별도로 수행한다. */
  private boolean passes(LogLevel level) {
    if (!SuhLogSettings.isEnabled()) {
      return false;
    }
    LogLevel min = SuhLogSettings.getMinLevel();
    return min == null || level.isAtLeast(min);
  }

  @Override
  public void trace(String message) {
    if (passes(LogLevel.TRACE)) delegate().trace(message);
  }

  @Override
  public void trace(String message, Object... args) {
    if (passes(LogLevel.TRACE)) delegate().trace(message, args);
  }

  @Override
  public void debug(String message) {
    if (passes(LogLevel.DEBUG)) delegate().debug(message);
  }

  @Override
  public void debug(String message, Object... args) {
    if (passes(LogLevel.DEBUG)) delegate().debug(message, args);
  }

  @Override
  public void info(String message) {
    if (passes(LogLevel.INFO)) delegate().info(message);
  }

  @Override
  public void info(String message, Object... args) {
    if (passes(LogLevel.INFO)) delegate().info(message, args);
  }

  @Override
  public void warn(String message) {
    if (passes(LogLevel.WARN)) delegate().warn(message);
  }

  @Override
  public void warn(String message, Object... args) {
    if (passes(LogLevel.WARN)) delegate().warn(message, args);
  }

  @Override
  public void error(String message) {
    if (passes(LogLevel.ERROR)) delegate().error(message);
  }

  @Override
  public void error(String message, Object... args) {
    if (passes(LogLevel.ERROR)) delegate().error(message, args);
  }

  @Override
  public void error(String message, Throwable throwable) {
    if (passes(LogLevel.ERROR)) delegate().error(message, throwable);
  }

  @Override
  public boolean isTraceEnabled() {
    return passes(LogLevel.TRACE) && delegate().isTraceEnabled();
  }

  @Override
  public boolean isDebugEnabled() {
    return passes(LogLevel.DEBUG) && delegate().isDebugEnabled();
  }

  @Override
  public boolean isInfoEnabled() {
    return passes(LogLevel.INFO) && delegate().isInfoEnabled();
  }

  @Override
  public boolean isWarnEnabled() {
    return passes(LogLevel.WARN) && delegate().isWarnEnabled();
  }

  @Override
  public boolean isErrorEnabled() {
    return passes(LogLevel.ERROR) && delegate().isErrorEnabled();
  }
}
```

```java
package kr.suhsaechan.suhapilog.autoconfigure;

import kr.suhsaechan.suhapilog.logging.LogLevel;
import kr.suhsaechan.suhapilog.logging.LoggerBackend;
import kr.suhsaechan.suhapilog.logging.SuhLogSettings;
import org.springframework.boot.SpringApplication;
import org.springframework.boot.env.EnvironmentPostProcessor;
import org.springframework.core.Ordered;
import org.springframework.core.env.ConfigurableEnvironment;

/**
 * 로깅 오버라이드 설정을 자동설정보다 훨씬 이른 시점에 주입한다.
 *
 * <p>라이브러리 로거는 static final로 클래스 로딩 시 만들어지므로, 빈 생성 이후에
 * 설정을 읽으면 이미 늦다. LOWEST_PRECEDENCE로 등록해 ConfigDataEnvironmentPostProcessor가
 * application.yml을 로드한 뒤에 실행되도록 한다.
 */
public class SuhApiLogEnvironmentPostProcessor implements EnvironmentPostProcessor, Ordered {

  private static final String PREFIX = "suhapilog.logging.";

  @Override
  public void postProcessEnvironment(ConfigurableEnvironment environment,
      SpringApplication application) {
    boolean enabled = environment.getProperty(PREFIX + "enabled", Boolean.class, Boolean.TRUE);
    LogLevel minLevel = LogLevel.parseOrNull(environment.getProperty(PREFIX + "level"));
    LoggerBackend backend = LoggerBackend.parseOrAuto(environment.getProperty(PREFIX + "backend"));

    SuhLogSettings.apply(enabled, minLevel, backend);
  }

  @Override
  public int getOrder() {
    return Ordered.LOWEST_PRECEDENCE;
  }
}
```

```java
package kr.suhsaechan.suhapilog.render;

import java.util.regex.Pattern;
import kr.suhsaechan.suhapilog.spi.TitleNormalizer;

/**
 * GitHub 페이지 title에서 메타정보를 걷어내는 기본 정제기.
 *
 * <p>정규식은 호출마다 재컴파일하지 않도록 상수로 올려둔다 — Swagger 렌더링 시
 * 이슈 개수만큼 반복 호출된다.
 */
public class DefaultTitleNormalizer implements TitleNormalizer {

  private static final String FALLBACK = "Unknown Title";
  private static final String GITHUB_META_MARKER = "· Issue";
  private static final Pattern BRACKET_TAG = Pattern.compile("\\[[^\\]]*\\]");
  private static final Pattern LEADING_SYMBOLS = Pattern.compile("^[^\\p{L}\\p{N}]+");
  private static final Pattern REPEATED_SPACE = Pattern.compile("\\s{2,}");

  @Override
  public String normalize(String rawTitle) {
    if (rawTitle == null || rawTitle.isEmpty()) {
      return FALLBACK;
    }

    String title = rawTitle;

    // "제목 · Issue #17 · owner/repo" 에서 앞부분만 취한다
    int metaIndex = title.indexOf(GITHUB_META_MARKER);
    if (metaIndex != -1) {
      title = title.substring(0, metaIndex).trim();
    }

    title = BRACKET_TAG.matcher(title).replaceAll("").trim();
    title = LEADING_SYMBOLS.matcher(title).replaceAll("").trim();
    title = REPEATED_SPACE.matcher(title).replaceAll(" ").trim();

    return title.isEmpty() ? FALLBACK : title;
  }
}
```

```java
    this.objectMapper = new ObjectMapper()
        .registerModule(new JavaTimeModule())
        .enable(SerializationFeature.INDENT_OUTPUT)
        .disable(SerializationFeature.WRITE_DATES_AS_TIMESTAMPS)
        .disable(DeserializationFeature.FAIL_ON_UNKNOWN_PROPERTIES);

    this.storageLocation = Paths.get(storagePath).toAbsolutePath().normalize();
    initializeStorage();
    loadIssues();
    loadHash();
  }

  private void initializeStorage() {
    try {
      Files.createDirectories(this.storageLocation);
    } catch (IOException e) {
      throw new IllegalStateException("저장소 디렉토리를 생성할 수 없습니다: " + this.storageLocation, e);
    }
  }

  private void loadIssues() {
    Path filePath = this.storageLocation.resolve(ISSUES_FILE);
    if (!Files.exists(filePath)) {
      return;
    }
    try {
      String content = Files.readString(filePath, StandardCharsets.UTF_8);
      List<IssueRef> issues = objectMapper.readValue(content, new TypeReference<>() {});
      for (IssueRef issue : issues) {
        if (issue.issueNumber() != null) {
          issueCache.put(issue.issueNumber(), issue);
        }
      }
      log.debug("GitHub 이슈 {}건을 로드했습니다", issues.size());
    } catch (Exception e) {
      // 캐시 파일이 깨져도 라이브러리는 살아 있어야 한다 — 빈 상태로 시작한다
      log.warn("이슈 캐시를 읽지 못해 빈 상태로 시작합니다: {}", e.getMessage());
    }
  }

  private void loadHash() {
    Path filePath = this.storageLocation.resolve(HASH_FILE);
    if (!Files.exists(filePath)) {
      return;
    }
    try {
      String content = Files.readString(filePath, StandardCharsets.UTF_8);
      Map<String, String> hashData =
          objectMapper.readValue(content, new TypeReference<Map<String, String>>() {});
      this.currentHash = hashData.getOrDefault("hash", "");
      log.debug("저장된 해시: {}", this.currentHash);
    } catch (Exception e) {
      log.warn("해시 데이터를 읽지 못했습니다: {}", e.getMessage());
    }
  }

  @Override
  public Optional<IssueRef> findByIssueNumber(int issueNumber) {
    return Optional.ofNullable(issueCache.get(issueNumber));
  }

  @Override
  public IssueRef save(IssueRef issue) {
    issueCache.put(issue.issueNumber(), issue);
    persistIssues();
    return issue;
  }

  @Override
  public Collection<IssueRef> findAll() {
    return new ArrayList<>(issueCache.values());
  }

  @Override
  public void saveAll(Collection<IssueRef> issues) {
    for (IssueRef issue : issues) {
      if (issue != null && issue.issueNumber() != null) {
        issueCache.put(issue.issueNumber(), issue);
      }
    }
    persistIssues(); // 건별이 아니라 한 번만 쓴다
  }

  @Override
  public String getCurrentHash() {
    return this.currentHash;
  }

  @Override
  public void updateHash(String hash) {
    Map<String, String> hashData = new LinkedHashMap<>();
    hashData.put("hash", hash);
    hashData.put("lastUpdated", LocalDateTime.now().toString());
    if (writeJson(HASH_FILE, hashData)) {
      this.currentHash = hash;
      log.debug("해시 갱신: {}", hash);
    }
  }

  private void persistIssues() {
    List<IssueRef> issues = new ArrayList<>(issueCache.values());
    if (writeJson(ISSUES_FILE, issues)) {
      log.debug("GitHub 이슈 {}건을 저장했습니다", issues.size());
    }
  }

  /**
   * 임시 파일에 쓴 뒤 원자적으로 교체한다.
   *
   * @return 성공 여부. 실패해도 예외를 던지지 않는다 — 캐시 저장 실패로 상위 앱을 죽이지 않는다
   */
  private boolean writeJson(String fileName, Object payload) {
    writeLock.lock();
    try {
      Path target = this.storageLocation.resolve(fileName);
      Path temp = this.storageLocation.resolve(fileName + ".tmp");

      String json = objectMapper.writeValueAsString(payload);
      Files.writeString(temp, json, StandardCharsets.UTF_8);

      try {
        Files.move(temp, target,
            StandardCopyOption.ATOMIC_MOVE, StandardCopyOption.REPLACE_EXISTING);
      } catch (AtomicMoveNotSupportedException e) {
        // 일부 파일시스템(네트워크 마운트 등)은 원자적 이동을 지원하지 않는다
        Files.move(temp, target, StandardCopyOption.REPLACE_EXISTING);
      }
      return true;
    } catch (Exception e) {
      log.warn("{} 저장에 실패했습니다: {}", fileName, e.getMessage());
      cleanupTemp(fileName);
      return false;
    } finally {
      writeLock.unlock();
    }
  }

  private void cleanupTemp(String fileName) {
    try {
      Files.deleteIfExists(this.storageLocation.resolve(fileName + ".tmp"));
    } catch (IOException ignored) {
      // 임시 파일 정리 실패는 무시한다 — 다음 쓰기에서 덮어쓴다
    }
  }
}
```

- [ ] **Step 4: `JsoupIssueFetcher` 작성**

```java
package kr.suhsaechan.suhapilog.fetch;

import java.io.IOException;
import java.time.Duration;
import java.time.Instant;
import java.time.LocalDateTime;
import java.util.Map;
import java.util.Optional;
import java.util.concurrent.ConcurrentHashMap;
import kr.suhsaechan.suhapilog.logging.SuhLog;
import kr.suhsaechan.suhapilog.logging.SuhLogger;
import kr.suhsaechan.suhapilog.spi.IssueFetcher;
import kr.suhsaechan.suhapilog.spi.IssueRef;
import kr.suhsaechan.suhapilog.spi.TitleNormalizer;
import kr.suhsaechan.suhapilog.util.SuhApiLogVersion;
import org.jsoup.Jsoup;
import org.jsoup.nodes.Document;

/**
 * GitHub 이슈 페이지의 title을 스크래핑하는 기본 조회 구현.
 *
 * <p>레거시 대비 달라진 점:
 * <ul>
 *   <li>timeout 설정 — 기존에는 무제한이라 GitHub가 느리면 부팅이 매달렸다</li>
 *   <li>재시도 + 백오프</li>
 *   <li>negative cache — 실패한 이슈를 Swagger 열 때마다 재요청하던 문제 차단</li>
 *   <li>예외를 던지지 않고 Optional.empty() 반환 — 상위 앱을 죽이지 않는다</li>
 * </ul>
 */
public class JsoupIssueFetcher implements IssueFetcher {

  private static final SuhLogger log = SuhLog.getLogger(JsoupIssueFetcher.class);

  /**
   * @param timeout     jsoup은 connect/read를 분리하지 않고 총 요청 시간 하나만 받는다
   * @param maxAttempts 최초 시도를 포함한 총 시도 횟수 (1이면 재시도 없음)
   * @param negativeTtl 실패를 기억하는 시간. Duration.ZERO면 negative cache를 쓰지 않는다
   */
  public record Options(
      Duration timeout,
      int maxAttempts,
      Duration backoff,
      String userAgent,
      Duration negativeTtl) {

    public static Options defaults() {
      return new Options(
          Duration.ofSeconds(5),
          2,
          Duration.ofMillis(500),
          "suh-api-log/" + SuhApiLogVersion.get(),
          Duration.ofMinutes(10));
    }
  }

  private final String baseUrl;
  private final TitleNormalizer titleNormalizer;
  private final Options options;
  private final Map<Integer, Instant> failedAt = new ConcurrentHashMap<>();

  public JsoupIssueFetcher(String baseUrl, TitleNormalizer titleNormalizer, Options options) {
    this.baseUrl = baseUrl;
    this.titleNormalizer = titleNormalizer;
    this.options = options;
  }

  @Override
  public Optional<IssueRef> fetch(int issueNumber) {
    if (isNegativelyCached(issueNumber)) {
      log.debug("이슈 {} 는 최근 조회에 실패해 재요청을 건너뜁니다", issueNumber);
      return Optional.empty();
    }

    String url = formatIssueUrl(baseUrl, issueNumber);
    int attempts = Math.max(1, options.maxAttempts());

    for (int attempt = 1; attempt <= attempts; attempt++) {
      try {
        String rawTitle = fetchRawTitle(url);
        failedAt.remove(issueNumber);
        return Optional.of(new IssueRef(
            issueNumber,
            titleNormalizer.normalize(rawTitle),
            rawTitle,
            url,
            LocalDateTime.now()));
      } catch (Exception e) {
        log.debug("이슈 {} 조회 {}/{} 실패: {}", issueNumber, attempt, attempts, e.getMessage());
        if (attempt < attempts) {
          sleepBackoff();
        }
      }
    }

    failedAt.put(issueNumber, Instant.now());
    log.warn("이슈 {} 조회에 실패했습니다: {}", issueNumber, url);
    return Optional.empty();
  }

  /** 네트워크 경계. 테스트에서 오버라이드한다. */
  protected String fetchRawTitle(String url) throws IOException {
    Document doc = Jsoup.connect(url)
        .userAgent(options.userAgent())
        .timeout((int) options.timeout().toMillis())
        .get();
    return doc.select("title").text();
  }

  private boolean isNegativelyCached(int issueNumber) {
    Duration ttl = options.negativeTtl();
    if (ttl == null || ttl.isZero() || ttl.isNegative()) {
      return false;
    }
    Instant at = failedAt.get(issueNumber);
    if (at == null) {
      return false;
    }
    if (Instant.now().isBefore(at.plus(ttl))) {
      return true;
    }
    failedAt.remove(issueNumber); // TTL이 지났으면 다시 시도할 기회를 준다
    return false;
  }

  private void sleepBackoff() {
    Duration backoff = options.backoff();
    if (backoff == null || backoff.isZero() || backoff.isNegative()) {
      return;
    }
    try {
      Thread.sleep(backoff.toMillis());
    } catch (InterruptedException e) {
      Thread.currentThread().interrupt();
    }
  }

  /** 끝 슬래시를 정리하고 /issues 경로가 없으면 붙인다. */
  public static String formatIssueUrl(String baseUrl, int issueNumber) {
    String normalized = baseUrl.replaceAll("/+$", "");
    if (!normalized.contains("/issues")) {
      normalized += "/issues";
    }
    return normalized + "/" + issueNumber;
  }
}
```

```java
package kr.suhsaechan.suhapilog.render;

import java.util.ArrayList;
import java.util.Arrays;
import java.util.Comparator;
import java.util.List;
import kr.suhsaechan.suhapilog.spi.ApiLogEntry;
import kr.suhsaechan.suhapilog.spi.ChangelogRenderer;

/**
 * 변경 이력을 HTML 표로 렌더링하는 기본 구현.
 *
 * <p>레거시에서는 이 로직이 GithubIssueService와 SwaggerIntegration에 두 벌 있었고
 * 이스케이프 규칙마저 달랐다(한쪽은 따옴표를 막지 않았다). 한 벌로 통합한다.
 */
public class HtmlTableChangelogRenderer implements ChangelogRenderer {

  public enum Column {
    DATE("date", "날짜"),
    AUTHOR("author", "작성자"),
    ISSUE_NUMBER("issue-number", "이슈번호"),
    ISSUE_TITLE("issue-title", "이슈 제목"),
    DESCRIPTION("description", "변경 내용");

    private final String key;
    private final String header;

    Column(String key, String header) {
      this.key = key;
      this.header = header;
    }

    public String header() {
      return header;
    }

    /** CSV 파싱. 유효한 값이 하나도 없으면 기본 컬럼 전체를 돌려준다. */
    public static List<Column> parse(String csv) {
      if (csv == null || csv.isBlank()) {
        return defaultColumns();
      }
      List<Column> parsed = new ArrayList<>();
      for (String token : csv.split(",")) {
        String key = token.trim().toLowerCase();
        for (Column column : values()) {
          if (column.key.equals(key) && !parsed.contains(column)) {
            parsed.add(column);
          }
        }
      }
      return parsed.isEmpty() ? defaultColumns() : List.copyOf(parsed);
    }

    static List<Column> defaultColumns() {
      return List.of(values());
    }
  }

  public enum Sort {
    NONE, DATE_ASC, DATE_DESC;

    public static Sort parseOrDefault(String value) {
      if (value == null || value.isBlank()) {
        return DATE_DESC;
      }
      String normalized = value.trim().toUpperCase().replace('-', '_');
      return Arrays.stream(values())
          .filter(s -> s.name().equals(normalized))
          .findFirst()
          .orElse(DATE_DESC);
    }
  }

  public record Options(List<Column> columns, Sort sort, String title, boolean escapeHtml) {

    public static Options defaults() {
      return new Options(Column.defaultColumns(), Sort.DATE_DESC, "API 변경 이력", true);
    }
  }

  private final Options options;

  public HtmlTableChangelogRenderer(Options options) {
    this.options = options;
  }

  @Override
  public String render(List<ApiLogEntry> entries) {
    if (entries == null || entries.isEmpty()) {
      return "";
    }

    List<ApiLogEntry> ordered = sorted(entries);
    List<Column> columns = options.columns();

    StringBuilder html = new StringBuilder();
    html.append("\n\n**").append(options.title()).append(":**\n")
        .append("<table><thead><tr>");
    for (Column column : columns) {
      html.append("<th>").append(column.header()).append("</th>");
    }
    html.append("</tr></thead><tbody>");

    for (ApiLogEntry entry : ordered) {
      html.append("<tr>");
      for (Column column : columns) {
        html.append("<td>").append(cell(entry, column)).append("</td>");
      }
      html.append("</tr>");
    }

    return html.append("</tbody></table>").toString();
  }

  private List<ApiLogEntry> sorted(List<ApiLogEntry> entries) {
    if (options.sort() == Sort.NONE) {
      return entries;
    }
    // date는 문자열이지만 YYYY-MM-DD 권장 포맷이라 사전순 == 시간순이다.
    // 포맷이 어긋난 값도 예외 없이 정렬되도록 null-safe 비교자를 쓴다.
    Comparator<ApiLogEntry> byDate =
        Comparator.comparing(e -> e.date() == null ? "" : e.date());
    List<ApiLogEntry> copy = new ArrayList<>(entries);
    copy.sort(options.sort() == Sort.DATE_ASC ? byDate : byDate.reversed());
    return copy;
  }

  private String cell(ApiLogEntry entry, Column column) {
    return switch (column) {
      case DATE -> escape(entry.date());
      case AUTHOR -> escape(entry.author());
      case DESCRIPTION -> escape(entry.description());
      case ISSUE_TITLE -> entry.issueNumber() > 0 ? escape(entry.issueTitle()) : "";
      case ISSUE_NUMBER -> issueLink(entry);
    };
  }

  private String issueLink(ApiLogEntry entry) {
    if (entry.issueNumber() <= 0) {
      return "";
    }
    // URL은 설정값 + 정수로 조립되므로 속성 인젝션 여지가 없지만, 방어적으로 이스케이프한다
    return "<a href=\"" + escapeAlways(entry.issueUrl()) + "\" target=\"_blank\">#"
        + entry.issueNumber() + "</a>";
  }

  private String escape(String text) {
    return options.escapeHtml() ? escapeAlways(text) : (text == null ? "" : text);
  }

  /** &, <, >, ", ' 다섯 문자를 모두 처리한다. */
  private static String escapeAlways(String text) {
    if (text == null) {
      return "";
    }
    return text.replace("&", "&amp;")
        .replace("<", "&lt;")
        .replace(">", "&gt;")
        .replace("\"", "&quot;")
        .replace("'", "&#39;");
  }
}
```

```java
package kr.suhsaechan.suhapilog.core;

import java.lang.reflect.Method;
import java.util.ArrayList;
import java.util.List;
import kr.suhsaechan.suhapilog.annotation.ApiLog;
import kr.suhsaechan.suhapilog.annotation.ApiLogs;
import org.springframework.core.annotation.MergedAnnotation;
import org.springframework.core.annotation.MergedAnnotations;

/**
 * @ApiLog 탐색을 한 곳으로 모은다.
 *
 * <p>레거시는 스캔 경로와 Swagger 경로가 서로 다른 방식(수동 인터페이스 순회 vs
 * MergedAnnotations)을 써서 결과가 어긋날 수 있었다. TYPE_HIERARCHY 한 가지로 통일한다.
 */
public final class ApiLogAnnotations {

  private static final ApiLog[] EMPTY = new ApiLog[0];

  private ApiLogAnnotations() {
  }

  /** 구현 클래스와 인터페이스 계층을 모두 뒤져 @ApiLog를 찾는다. 없으면 빈 배열. */
  public static ApiLog[] find(Method method) {
    if (method == null) {
      return EMPTY;
    }

    MergedAnnotations annotations =
        MergedAnnotations.from(method, MergedAnnotations.SearchStrategy.TYPE_HIERARCHY);

    // @Repeatable 컨테이너가 먼저다 — 여러 개 선언 시 @ApiLogs로 감싸진다
    MergedAnnotation<ApiLogs> container = annotations.get(ApiLogs.class);
    if (container.isPresent()) {
      return container.synthesize().value();
    }

    MergedAnnotation<ApiLog> single = annotations.get(ApiLog.class);
    if (single.isPresent()) {
      return new ApiLog[] {single.synthesize()};
    }

    return EMPTY;
  }

  /** issueNumber가 양수인 것만 추린다. */
  public static List<Integer> issueNumbersOf(ApiLog[] apiLogs) {
    List<Integer> numbers = new ArrayList<>();
    for (ApiLog apiLog : apiLogs) {
      if (apiLog.issueNumber() > 0) {
        numbers.add(apiLog.issueNumber());
      }
    }
    return numbers;
  }
}
```

```java
/**
 * 컨트롤러 클래스에서 @ApiLog의 이슈 번호를 수집한다.
 */
public final class ControllerScanner {

  private static final SuhLogger log = SuhLog.getLogger(ControllerScanner.class);

  private ControllerScanner() {
  }

  /** @return 정렬된 이슈 번호 집합. 해시 계산이 순서에 의존하므로 TreeSet을 쓴다. */
  public static Set<Integer> collectIssueNumbers(Class<?>... sources) {
    Set<Integer> issueNumbers = new TreeSet<>();
    if (sources == null) {
      return issueNumbers;
    }

    for (Class<?> source : sources) {
      if (source == null) {
        continue;
      }
      Class<?> target = unwrap(source);
      for (Method method : target.getMethods()) {
        ApiLog[] apiLogs = ApiLogAnnotations.find(method);
        if (apiLogs.length > 0) {
          issueNumbers.addAll(ApiLogAnnotations.issueNumbersOf(apiLogs));
        }
      }
    }

    log.debug("컨트롤러 {}개에서 이슈 번호 {}건 수집", sources.length, issueNumbers.size());
    return issueNumbers;
  }

  /**
   * CGLIB 프록시라면 원본 클래스를 돌려준다.
   * 레거시의 {@code getName().contains("$$")} 문자열 검사보다 정확하다.
   */
  public static Class<?> unwrap(Class<?> candidate) {
    return ClassUtils.getUserClass(candidate);
  }
}
```

```java
package kr.suhsaechan.suhapilog.core;

import java.time.Duration;
import java.time.LocalDateTime;
import java.util.ArrayList;
import java.util.Collection;
import java.util.List;
import java.util.Optional;
import java.util.concurrent.Callable;
import java.util.concurrent.ExecutorService;
import java.util.concurrent.Executors;
import java.util.concurrent.Future;
import java.util.concurrent.TimeUnit;
import kr.suhsaechan.suhapilog.logging.SuhLog;
import kr.suhsaechan.suhapilog.logging.SuhLogger;
import kr.suhsaechan.suhapilog.spi.IssueFetcher;
import kr.suhsaechan.suhapilog.spi.IssueRef;
import kr.suhsaechan.suhapilog.spi.IssueRepository;

/**
 * 캐시 우선 이슈 해석기.
 *
 * <p>캐시에 있으면 그대로 쓰고, 없거나 TTL이 지났으면 fetcher로 조회한 뒤 저장한다.
 * 어떤 실패에도 예외를 전파하지 않는다 — 문서화 보조 기능이 상위 앱을 죽이면 안 된다.
 */
public class IssueResolver {

  private static final SuhLogger log = SuhLog.getLogger(IssueResolver.class);

  private final IssueRepository repository;
  private final IssueFetcher fetcher;
  private final Duration cacheTtl;

  /** @param cacheTtl null이거나 0 이하면 캐시를 무기한 사용한다 */
  public IssueResolver(IssueRepository repository, IssueFetcher fetcher, Duration cacheTtl) {
    this.repository = repository;
    this.fetcher = fetcher;
    this.cacheTtl = cacheTtl;
  }

  public Optional<IssueRef> resolve(int issueNumber) {
    Optional<IssueRef> cached = repository.findByIssueNumber(issueNumber);
    if (cached.isPresent() && isFresh(cached.get())) {
      return cached;
    }

    Optional<IssueRef> fetched = fetcher.fetch(issueNumber);
    if (fetched.isPresent()) {
      repository.save(fetched.get());
      return fetched;
    }

    // 조회에 실패해도 만료된 캐시가 있으면 그거라도 보여주는 게 빈칸보다 낫다
    return cached;
  }

  /**
   * 여러 이슈를 병렬로 해석한다.
   *
   * @param concurrency 1 이하면 순차 처리
   * @return 해석에 성공한 것만. 순서는 보장하지 않는다
   */
  public List<IssueRef> resolveAll(Collection<Integer> issueNumbers, int concurrency) {
    if (issueNumbers == null || issueNumbers.isEmpty()) {
      return List.of();
    }

    if (concurrency <= 1) {
      List<IssueRef> results = new ArrayList<>();
      for (Integer number : issueNumbers) {
        resolve(number).ifPresent(results::add);
      }
      return results;
    }

    int poolSize = Math.min(concurrency, issueNumbers.size());
    ExecutorService pool = Executors.newFixedThreadPool(poolSize, runnable -> {
      Thread thread = new Thread(runnable, "suh-api-log-issue-fetch");
      thread.setDaemon(true); // 조회가 늦어져도 JVM 종료를 막지 않는다
      return thread;
    });

    try {
      List<Callable<Optional<IssueRef>>> tasks = new ArrayList<>();
      for (Integer number : issueNumbers) {
        tasks.add(() -> resolve(number));
      }

      List<IssueRef> results = new ArrayList<>();
      for (Future<Optional<IssueRef>> future : pool.invokeAll(tasks)) {
        try {
          future.get().ifPresent(results::add);
        } catch (Exception e) {
          log.debug("이슈 해석 중 오류: {}", e.getMessage());
        }
      }
      return results;
    } catch (InterruptedException e) {
      Thread.currentThread().interrupt();
      return List.of();
    } finally {
      pool.shutdown();
      try {
        pool.awaitTermination(1, TimeUnit.SECONDS);
      } catch (InterruptedException e) {
        Thread.currentThread().interrupt();
      }
    }
  }

  private boolean isFresh(IssueRef issue) {
    if (cacheTtl == null || cacheTtl.isZero() || cacheTtl.isNegative()) {
      return true; // TTL 미설정 = 무기한 유효
    }
    LocalDateTime fetchedAt = issue.fetchedAt();
    if (fetchedAt == null) {
      return false; // 3.0.0 이전 캐시에는 조회 시각이 없다 — 갱신 대상으로 본다
    }
    return fetchedAt.plus(cacheTtl).isAfter(LocalDateTime.now());
  }
}
```

```java
package kr.suhsaechan.suhapilog.core;

import java.lang.reflect.Method;
import java.util.ArrayList;
import java.util.List;
import kr.suhsaechan.suhapilog.annotation.ApiLog;
import kr.suhsaechan.suhapilog.fetch.JsoupIssueFetcher;
import kr.suhsaechan.suhapilog.spi.ApiLogEntry;
import kr.suhsaechan.suhapilog.spi.ChangelogRenderer;
import kr.suhsaechan.suhapilog.spi.IssueRef;

/**
 * @ApiLog 어노테이션을 렌더링 가능한 엔트리로 정규화한다.
 *
 * <p>author 기본값 폴백이 실제로 적용되는 유일한 지점이다. 레거시는 폴백 값을
 * 계산해두고 출력 시에는 어노테이션 값을 그대로 써서 default-author 설정이
 * 동작하지 않았다.
 */
public class ChangelogService {

  private final IssueResolver issueResolver;
  private final ChangelogRenderer renderer;
  private final String issueBaseUrl;
  private final String defaultAuthor;

  public ChangelogService(IssueResolver issueResolver, ChangelogRenderer renderer,
      String issueBaseUrl, String defaultAuthor) {
    this.issueResolver = issueResolver;
    this.renderer = renderer;
    this.issueBaseUrl = issueBaseUrl;
    this.defaultAuthor = (defaultAuthor == null) ? "" : defaultAuthor;
  }

  public List<ApiLogEntry> toEntries(Method method) {
    ApiLog[] apiLogs = ApiLogAnnotations.find(method);
    if (apiLogs.length == 0) {
      return List.of();
    }

    List<ApiLogEntry> entries = new ArrayList<>(apiLogs.length);
    for (ApiLog apiLog : apiLogs) {
      entries.add(toEntry(apiLog));
    }
    return entries;
  }

  public String renderFor(Method method) {
    List<ApiLogEntry> entries = toEntries(method);
    return entries.isEmpty() ? "" : renderer.render(entries);
  }

  private ApiLogEntry toEntry(ApiLog apiLog) {
    String author = apiLog.author();
    if (author == null || author.isBlank()) {
      author = defaultAuthor;
    }

    int issueNumber = apiLog.issueNumber();
    if (issueNumber <= 0) {
      return new ApiLogEntry(apiLog.date(), author, apiLog.description(), issueNumber, "", "");
    }

    // 이슈 링크는 조회 성공 여부와 무관하게 만들 수 있다 — 제목만 비워둔다
    String issueUrl = hasBaseUrl()
        ? JsoupIssueFetcher.formatIssueUrl(issueBaseUrl, issueNumber)
        : "";
    String issueTitle = issueResolver.resolve(issueNumber)
        .map(IssueRef::cleanTitle)
        .orElse("");

    return new ApiLogEntry(
        apiLog.date(), author, apiLog.description(), issueNumber, issueUrl, issueTitle);
  }

  private boolean hasBaseUrl() {
    return issueBaseUrl != null && !issueBaseUrl.isBlank();
  }
}
```

```java
package kr.suhsaechan.suhapilog.core;

import java.nio.charset.StandardCharsets;
import java.security.MessageDigest;
import java.security.NoSuchAlgorithmException;
import java.util.ArrayList;
import java.util.Collection;
import java.util.HexFormat;
import java.util.List;
import java.util.Set;
import kr.suhsaechan.suhapilog.logging.SuhLog;
import kr.suhsaechan.suhapilog.logging.SuhLogger;
import kr.suhsaechan.suhapilog.spi.IssueRef;
import kr.suhsaechan.suhapilog.spi.IssueRepository;

/**
 * 부팅 시 이슈 캐시를 워밍업한다.
 *
 * <p>레거시는 해시를 계산해 저장만 하고 아무도 읽지 않아, 변경이 없어도 매 기동마다
 * 전량을 재조회했다. 이제 해시가 같고 캐시가 온전하면 네트워크 요청을 0회로 만든다.
 */
public class IssueSyncCoordinator {

  private static final SuhLogger log = SuhLog.getLogger(IssueSyncCoordinator.class);

  private final IssueResolver issueResolver;
  private final IssueRepository repository;
  private final int concurrency;

  public IssueSyncCoordinator(IssueResolver issueResolver, IssueRepository repository,
      int concurrency) {
    this.issueResolver = issueResolver;
    this.repository = repository;
    this.concurrency = concurrency;
  }

  /**
   * @return 실제로 조회를 수행했으면 true, 스킵했거나 대상이 없으면 false
   */
  public boolean sync(Class<?>... sources) {
    Set<Integer> issueNumbers = ControllerScanner.collectIssueNumbers(sources);
    if (issueNumbers.isEmpty()) {
      log.debug("컨트롤러에서 @ApiLog 이슈 번호를 찾지 못했습니다");
      return false;
    }

    String hash = hashOf(issueNumbers);
    if (hash.equals(repository.getCurrentHash()) && isCacheComplete(issueNumbers)) {
      log.debug("이슈 목록이 이전과 동일하고 캐시가 온전해 동기화를 건너뜁니다 ({}건)",
          issueNumbers.size());
      return false;
    }

    log.info("API 변경 이력 이슈 {}건 동기화를 시작합니다", issueNumbers.size());
    List<IssueRef> resolved = issueResolver.resolveAll(issueNumbers, concurrency);
    if (!resolved.isEmpty()) {
      repository.saveAll(resolved);
    }
    repository.updateHash(hash);
    log.info("API 변경 이력 동기화 완료 ({}/{}건 성공)", resolved.size(), issueNumbers.size());
    return true;
  }

  /** 해시가 같아도 캐시 파일이 지워졌을 수 있으므로 실제 보유 여부를 확인한다. */
  private boolean isCacheComplete(Collection<Integer> issueNumbers) {
    for (Integer number : issueNumbers) {
      if (repository.findByIssueNumber(number).isEmpty()) {
        return false;
      }
    }
    return true;
  }

  /** 이슈 번호 집합의 SHA-256. 입력 순서와 무관하게 동일한 값을 낸다. */
  public static String hashOf(Collection<Integer> issueNumbers) {
    if (issueNumbers == null || issueNumbers.isEmpty()) {
      return "";
    }
    List<Integer> sorted = new ArrayList<>(issueNumbers);
    sorted.sort(Integer::compareTo);

    StringBuilder joined = new StringBuilder();
    for (Integer number : sorted) {
      joined.append(number).append(',');
    }

    try {
      MessageDigest digest = MessageDigest.getInstance("SHA-256");
      byte[] bytes = digest.digest(joined.toString().getBytes(StandardCharsets.UTF_8));
      return HexFormat.of().formatHex(bytes);
    } catch (NoSuchAlgorithmException e) {
      // SHA-256은 JDK 표준이라 실제로는 도달하지 않는다. 도달해도 앱을 죽이지 않는다.
      log.warn("해시 계산에 실패해 동기화 스킵 최적화를 사용하지 않습니다: {}", e.getMessage());
      return "";
    }
  }
}
```

```java
package kr.suhsaechan.suhapilog.integration;

import io.swagger.v3.oas.models.Operation;
import kr.suhsaechan.suhapilog.core.ChangelogService;
import kr.suhsaechan.suhapilog.logging.SuhLog;
import kr.suhsaechan.suhapilog.logging.SuhLogger;
import org.springdoc.core.customizers.OperationCustomizer;
import org.springframework.web.method.HandlerMethod;

/**
 * Swagger UI의 오퍼레이션 설명에 변경 이력 표를 덧붙인다.
 *
 * <p>레거시는 springdoc 의존 여부를 몰라 리플렉션 Proxy로 인터페이스를 구현하고
 * 빈 타입을 Object로 선언했다. 그 탓에 springdoc의 타입 기반 빈 수집에서 누락될
 * 위험이 있었다. 이제 @ConditionalOnClass가 클래스패스 존재를 보장하므로
 * 인터페이스를 직접 구현한다.
 */
public class SpringDocOperationCustomizer implements OperationCustomizer {

  private static final SuhLogger log = SuhLog.getLogger(SpringDocOperationCustomizer.class);

  private final ChangelogService changelogService;

  public SpringDocOperationCustomizer(ChangelogService changelogService) {
    this.changelogService = changelogService;
  }

  @Override
  public Operation customize(Operation operation, HandlerMethod handlerMethod) {
    if (operation == null || handlerMethod == null) {
      return operation;
    }

    try {
      String table = changelogService.renderFor(handlerMethod.getMethod());
      if (table.isEmpty()) {
        return operation;
      }
      String original = (operation.getDescription() == null) ? "" : operation.getDescription();
      operation.setDescription(original + table);
    } catch (Exception e) {
      // 문서 장식 실패로 Swagger 문서 생성 전체를 깨뜨리지 않는다
      log.warn("변경 이력 렌더링에 실패했습니다 ({}): {}",
          handlerMethod.getMethod().getName(), e.getMessage());
    }

    return operation;
  }
}
```

```java
/**
 * suh-api-log 자동설정.
 *
 * <p>SPI 4종은 모두 {@code @ConditionalOnMissingBean}이라, 상위 프로젝트가 같은 타입
 * 빈 하나만 등록하면 기본 구현이 물러난다.

@AutoConfiguration
@EnableConfigurationProperties(ApiChangeLogProperties.class)
@ConditionalOnProperty(prefix = "suhapilog", name = "enabled", havingValue = "true",
    matchIfMissing = true)
public class SuhApiLogAutoConfiguration {

  private static final SuhLogger log = SuhLog.getLogger(SuhApiLogAutoConfiguration.class);

  @Bean
  @ConditionalOnMissingBean
  public TitleNormalizer suhApiLogTitleNormalizer() {
    return new DefaultTitleNormalizer();
  }

  @Bean
  @ConditionalOnMissingBean
  public IssueRepository suhApiLogIssueRepository(ApiChangeLogProperties properties) {
    String path = ProjectRootResolver
        .resolveStoragePath(properties.getStorage().getPath())
        .toString();
    return new JsonIssueRepository(path);
  }

  @Bean
  @ConditionalOnMissingBean
  public IssueFetcher suhApiLogIssueFetcher(ApiChangeLogProperties properties,
      TitleNormalizer titleNormalizer) {
    ApiChangeLogProperties.Github github = properties.getGithub();
    String userAgent = (github.getUserAgent() == null || github.getUserAgent().isBlank())
        ? "suh-api-log/" + SuhApiLogVersion.get()
        : github.getUserAgent();

    JsoupIssueFetcher.Options options = new JsoupIssueFetcher.Options(
        github.getTimeout(),
        github.getRetry().getMaxAttempts(),
        github.getRetry().getBackoff(),

    return new JsoupIssueFetcher(github.getBaseUrl(), titleNormalizer, options);

  @Bean
  @ConditionalOnMissingBean
  public ChangelogRenderer suhApiLogChangelogRenderer(ApiChangeLogProperties properties) {
    ApiChangeLogProperties.Render render = properties.getRender();
    HtmlTableChangelogRenderer.Options options = new HtmlTableChangelogRenderer.Options(
        HtmlTableChangelogRenderer.Column.parse(render.getColumns()),
        HtmlTableChangelogRenderer.Sort.parseOrDefault(render.getSort()),
        render.getTitle(),
        render.isEscapeHtml());
    return new HtmlTableChangelogRenderer(options);
  }

  @Bean
  @ConditionalOnMissingBean
  public IssueResolver suhApiLogIssueResolver(IssueRepository repository, IssueFetcher fetcher,
      ApiChangeLogProperties properties) {
    Duration ttl = properties.getGithub().getCache().getTtl();
    return new IssueResolver(repository, fetcher, ttl);
  }

  @Bean
  @ConditionalOnMissingBean
  public ChangelogService suhApiLogChangelogService(IssueResolver issueResolver,
      ChangelogRenderer renderer, ApiChangeLogProperties properties) {
    return new ChangelogService(issueResolver, renderer,
        properties.getGithub().getBaseUrl(), properties.getDefaultAuthor());
  }

  @Bean
  @ConditionalOnMissingBean
  public IssueSyncCoordinator suhApiLogIssueSyncCoordinator(IssueResolver issueResolver,
      IssueRepository repository, ApiChangeLogProperties properties) {
    return new IssueSyncCoordinator(issueResolver, repository,
        properties.getGithub().getConcurrency());
  }

  /**
   * 부팅 시 이슈 캐시 워밍업.
   *
   * <p>기본 startup-mode가 ASYNC라 부팅을 막지 않는다. base-url이 없으면 경고만 남기고
   * 이슈 연동을 끈다 — fail-fast=true일 때만 예외를 던진다.
   */
  @Bean
  @ConditionalOnProperty(prefix = "suhapilog.github", name = "startup-mode",
      havingValue = "lazy", matchIfMissing = true)
  public ApplicationRunner suhApiLogChangelogInitializer(IssueSyncCoordinator coordinator,
      ApplicationContext context, ApiChangeLogProperties properties) {
    return args -> {
      ApiChangeLogProperties.Github github = properties.getGithub();

      if (github.getBaseUrl() == null || github.getBaseUrl().isBlank()) {
        String message = "suhapilog.github.base-url이 설정되지 않아 이슈 연동을 비활성화합니다. "
            + "application.yml에 suhapilog.github.base-url="
            + "https://github.com/{owner}/{repo}/issues/ 를 추가하세요.";
        if (github.isFailFast()) {
          throw new IllegalStateException(message);
        }
        log.warn(message);
        return;
      }

      if (github.getStartupMode() == StartupMode.LAZY) {
        log.debug("startup-mode=lazy — 부팅 시 이슈 동기화를 건너뜁니다");
        return;
      }

      Class<?>[] controllers = collectControllerClasses(context);
      Runnable task = () -> {
        try {
          coordinator.sync(controllers);
        } catch (Exception e) {
          log.error("API 변경 이력 동기화 중 오류가 발생했습니다: {}", e.getMessage(), e);
        }
      };

      if (github.getStartupMode() == StartupMode.BLOCKING) {
        task.run();
      } else {
        Thread thread = new Thread(task, "suh-api-log-startup-sync");
        thread.setDaemon(true); // 동기화가 늦어져도 JVM 종료를 막지 않는다
        thread.start();
      }
    };
  }

  /**
   * 컨트롤러 클래스를 수집한다.
   *
   * <p>빈 인스턴스가 아니라 빈 <b>정의</b>의 타입을 읽어, 레거시처럼 모든 컨트롤러를
   * 강제로 조기 초기화하지 않는다.
   */
  private Class<?>[] collectControllerClasses(ApplicationContext context) {
    java.util.Set<Class<?>> classes = new java.util.LinkedHashSet<>();
    for (String name : context.getBeanNamesForAnnotation(RestController.class)) {
      addType(context, classes, name);
    }
    for (String name : context.getBeanNamesForAnnotation(Controller.class)) {
      addType(context, classes, name);
    }
    return classes.toArray(Class<?>[]::new);
  }

  private void addType(ApplicationContext context, java.util.Set<Class<?>> classes, String name) {
    Class<?> type = context.getType(name);
    if (type != null) {
      classes.add(ControllerScanner.unwrap(type));
    }
  }

  /**
   * springdoc이 클래스패스에 있을 때만 활성화된다.
   */
  @Configuration(proxyBeanMethods = false)
  @ConditionalOnClass(OperationCustomizer.class)
  static class SpringDocIntegrationConfiguration {

    @Bean
    @ConditionalOnMissingBean
    SpringDocOperationCustomizer suhApiLogOperationCustomizer(ChangelogService changelogService) {
      return new SpringDocOperationCustomizer(changelogService);
    }
  }
```
